Order Confirmation Calls

Auto-call customers when an order is placed. Integrate with any ecommerce platform via a simple REST API or webhook.

Call Configuration
Placeholders: {customer_name} {order_id} {total_amount} {items}
Assign an IVR flow to collect delivery confirmation from the customer.
Test Order Call
API Reference REST
POST /api/v1/order-call
Authentication
X-API-Key: YOUR_API_KEY
Request Body (JSON)
{
  "phone":         "+8801XXXXXXXXX",
  "order_id":      "ORD-2024-001",
  "customer_name": "Rahul Islam",
  "total_amount":  "1,250 BDT",
  "items":         "2x T-Shirt, 1x Cap",
  "message":       "(optional override text)"
}
Success Response
{
  "success": true,
  "call_id": 42,
  "message": "Order confirmation call initiated"
}
cURL Example
curl -X POST \
  {{ request.host_url }}api/v1/order-call \
  -H "X-API-Key: {{ api_key or 'YOUR_KEY' }}" \
  -H "Content-Type: application/json" \
  -d '{"phone":"+8801700000000","order_id":"ORD1","customer_name":"Test","total_amount":"500 BDT"}'
WooCommerce Hook
add_action('woocommerce_order_status_processing',
  function($order_id) {
    $order = wc_get_order($order_id);
    wp_remote_post('{{ request.host_url }}api/v1/order-call', [
      'headers' => ['X-API-Key' => 'YOUR_KEY',
                    'Content-Type' => 'application/json'],
      'body' => json_encode([
        'phone'         => $order->get_billing_phone(),
        'order_id'      => $order_id,
        'customer_name' => $order->get_billing_first_name(),
        'total_amount'  => $order->get_formatted_order_total(),
      ])
    ]);
  }
);
Platform Integrations
Shopify
Create an Order webhook pointing to /api/v1/order-call in Settings → Notifications → Webhooks. Map phone from order.phone or order.billing_address.phone.
WooCommerce
Use the PHP snippet above in your theme's functions.php. Fires when payment is received and order status changes to Processing.
Any Platform
Send a POST request from any webhook or backend. The only required field is phone. Use message to override the default TTS script entirely.
n8n / Zapier
Add an HTTP Request node triggered on "New Order". Set method to POST, URL to your C-Call endpoint, and add X-API-Key as a custom header.
