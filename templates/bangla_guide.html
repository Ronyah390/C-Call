বাংলা ব্যবহার নির্দেশিকা

C-Call IVR ব্যবহার গাইড

প্রথমবার ব্যবহারকারীর জন্য সহজ ভাষায় সেটআপ, কল পাঠানো, IVR ফ্লো বানানো, ভয়েস টেস্ট, ই-কমার্স ইন্টিগ্রেশন এবং সমস্যার সমাধান।

১. এই প্ল্যাটফর্ম কী করে?

C-Call IVR দিয়ে আপনি নিজের SIP/VoIP অ্যাকাউন্ট ব্যবহার করে অটোমেটেড ভয়েস কল পাঠাতে পারবেন। দুই ধরনের কাজ করা যায়: একমুখী ভয়েস ব্রডকাস্ট এবং ইন্টারঅ্যাকটিভ IVR মেনু।

Direct Voice Call
একটি লেখা TTS দিয়ে ভয়েস বানিয়ে বা অডিও ফাইল আপলোড করে এক বা একাধিক নম্বরে কল পাঠানো।
Interactive IVR
কল ধরার পর গ্রাহক ১, ২, ৩ বা ০ চাপলে আলাদা মেনু, বার্তা বা প্রতিনিধির কাছে ট্রান্সফার।
২. প্রথমবার সেটআপ
  1. Settings পেজে যান।
  2. SIP Account অংশে আপনার SIP Domain, Port, Username এবং Password দিন। সাধারণত Port হয় 5060।
  3. Dial Format ঠিক করুন। বাংলাদেশি নম্বরের জন্য আগে Local BD চেষ্টা করুন। কল না গেলে E.164 বা Digits only চেষ্টা করুন।
  4. TTS Providers অংশে gTTS, ElevenLabs বা Gemini নির্বাচন করুন।
  5. ElevenLabs/Gemini ব্যবহার করলে API key দিন, তারপর Test API, Fetch Voices এবং Test Voice দিয়ে যাচাই করুন।
  6. সবশেষে Save All Settings চাপুন।
কলের অডিও যদি Settings পেজে পরিষ্কার শোনায় কিন্তু ফোন কলে মাঝে মাঝে ভাঙা শোনায়, তাহলে সাধারণত সেটি SIP/RTP নেটওয়ার্ক বা provider route issue।
৩. Bangla Solar Panel Demo IVR ব্যবহার

Flows পেজে গিয়ে Add Bangla Solar Panel Demo IVR চাপলে একটি প্রস্তুত ডেমো ফ্লো তৈরি হবে। এটি সোলার প্যানেল ব্যবসার জন্য বানানো, কিন্তু আপনি পরে প্রতিটি অংশ নিজের ব্যবসার মতো করে এডিট করতে পারবেন।

কিপ্যাড ডেমো মেনু কাজ
1নতুন কোটেশনবাসা, ব্যবসা, সেচ পাম্প কোটেশন অপশন।
2প্যাকেজ তথ্য১ কিলোওয়াট, ৩ কিলোওয়াট, ব্যাটারি ব্যাকআপ।
3সার্ভিস সাপোর্টইনভার্টার, ব্যাটারি, প্যানেল মেইনটেন্যান্স।
4EMI ও পেমেন্টকিস্তি এবং পেমেন্ট তথ্যের বার্তা।
0প্রতিনিধিমানুষের কাছে কল ট্রান্সফার করার জন্য।
9মূল মেনুসাব-মেনু থেকে আবার শুরুতে ফিরে যায়।
৪. নিজের IVR Flow বানানো বা এডিট করা
  1. Flows পেজে নতুন Flow তৈরি করুন অথবা ডেমো Flow থেকে Edit Flow চাপুন।
  2. Add Menu Node থেকে নতুন node যোগ করুন। Node হলো কলের একটি ধাপ।
  3. Menu node গ্রাহকের keypad input নেয়। যেমন: “সেলসের জন্য ১ চাপুন।”
  4. Message node শুধু বার্তা শুনিয়ে কল শেষ করে।
  5. Transfer node কলকে অন্য নম্বরে পাঠায়। Transfer number ঠিক করে দিন।
  6. Connect Keypresses দিয়ে কোন key চাপলে কোন node-এ যাবে তা map করুন।
  7. Entry Point থেকে কোন node দিয়ে কল শুরু হবে তা সেট করুন।

Flow পুরোপুরি মুছতে চাইলে Flows list বা Edit Flow পেজ থেকে Delete Flow ব্যবহার করুন।

৫. কল পাঠানোর নিয়ম

Single Call

  1. Dashboard-এ Phone Number দিন।
  2. Call Mode হিসেবে IVR Flow বা One-way Audio Message বেছে নিন।
  3. IVR হলে Flow নির্বাচন করুন। Direct হলে TTS message লিখুন বা audio upload করুন।
  4. Launch Call চাপুন।

Bulk Call

  1. প্রতি লাইনে একটি নম্বর লিখুন অথবা CSV upload করুন।
  2. IVR বা Direct mode নির্বাচন করুন।
  3. Message/Flow ঠিক করে Launch Bulk Call চাপুন।
৬. Ecommerce Order Call

Ecommerce পেজ থেকে API key পাবেন। WooCommerce, Shopify, n8n, Zapier বা নিজের backend থেকে order তৈরি হলে /api/v1/order-call endpoint-এ POST request পাঠিয়ে গ্রাহককে অটো কল করা যায়।

আগে Test Order Call ফর্ম দিয়ে নিজের নম্বরে একটি টেস্ট কল পাঠিয়ে নিশ্চিত হন।

৭. সাধারণ সমস্যা ও সমাধান
সমস্যা সমাধান
SIP Ready দেখাচ্ছে না Settings-এ SIP Domain, User, Password ঠিক আছে কিনা দেখুন। Password blank রাখলে পুরনো password থাকবে।
কল যাচ্ছে না বা 503 আসছে Dial Format বদলে দেখুন। Local BD, E.164, Digits only আলাদা provider-এ আলাদা কাজ করতে পারে।
TTS কাজ করছে না Settings থেকে Test API এবং Test Voice চালান। ElevenLabs হলে আগে Fetch Voices করুন। Gemini হলে 2.5 Flash model ব্যবহার করুন।
অডিও কলে ভাঙা শোনায় Settings preview পরিষ্কার হলে সমস্যা সাধারণত network jitter, SIP provider route, CGNAT, Wi-Fi বা UDP packet loss।
রেকর্ডিং বা audio conversion fail FFmpeg install আছে কিনা এবং FFMPEG_PATH ঠিক আছে কিনা দেখুন।
